## 3.1　使用 SPICE 模拟分析模拟电路

### 3.1.1　为何要使用电路模拟器

模拟电路以设计自由度极高为其特征。然而其自动设计趋于困难，从电路的构想开始直至设计为止都要依赖人工。由于靠人工的设计难免有所疏漏与错误，因此一次设计一般都无法达成目标的规格要求。

从前的电路设计工程师，为了“设计—试作—测试—再设计……”的循环作业忙得团团转。如今电子电路的工作能够轻而易举地利用可在电脑上模拟的电路模拟器 SPICE 进行模拟。

当输入电路资料时，SPICE 开始对电路动作进行分析：各部分的信号波形宛如在示波器上看到的一样，频率特性则如同用电路分析仪观测，并在图表上显示分析结果。总之，灵活运用 SPICE 可大幅缩减耗费在试作与测试上的时间。

### 3.1.2　什么是 SPICE

电子电路模拟器正式称呼为 SPICE。SPICE 是由加利福尼亚大学伯克利分校（U. C. Berkeley）所研发的 **Simulation Program with Integrated Circuit Emphasis** 的首字母缩写。从名称即可明白，它是为模拟以晶体管为基础的集成电路而设计的软件，而且个别半导体电路和被动电路（LC 滤波器和传送线路等）也均可模拟。

<!-- 来源：PDF 第 64 页；原书第 50 页 -->

最初的 SPICE 于 1972 年公开。1975 年出现 SPICE2，1981 年正式命名为 SPICE2G6。1980 年代以后，各厂商把伯克利版 SPICE 改良、扩充后作为产品发售，SPICE 遂成为电路设计工程师不可缺少的工具。

表 3.1 展示了在 Windows 环境下工作的代表性商业 SPICE 产品（原书调查时间为 2002 年 7 月）。价格大致随元件库的充实程度与使用便利性而增加。很多厂商也提供限制电路规模的评价版或有时限的试用版；对于小电路，评价版也足够使用。

![表 3.1　市场销售的代表性 SPICE 产品（2002 年 7 月）](../images/table-03-01.png)

上世纪 80 年代，伯克利版 SPICE 也持续发展，增强了图形功能、增加了元件模型并改善收敛性，由此诞生 SPICE3。它原是在 UNIX 环境中运行的公共领域软件，后来也出现许多在 Windows 环境中运行的移植版。伯克利版及其移植版在易用性方面不及商业产品，但免费且不限制电路规模，仍有其吸引力。

### 3.1.3　SPICE 的电路文件（File）

在伯克利版 SPICE 中，电路资料以称为网表（Netlist）的文本文件形式输入模拟器。

另一方面，不少商业版 SPICE 可直接从电路图编辑器制作电路图文件，再由软件自动生成网表并分析；也有许多产品和伯克利版一样，可以直接输入网表。各公司产品的电路文件形式虽有不同，网表的记述形式仍大多以伯克利版 SPICE2 或 SPICE3 为准。

### 3.1.4　仍须模型参数（Model Parameter）

若想用 SPICE 正确模拟电路动作，就必须采用正确的模型参数。模型参数是规定元件特性的基本常数。以双极性晶体管（Bipolar Transistor）为例，包括饱和电流、电流放大倍数、结电容等数十个参数。

![表 3.3（上）　双极性晶体管（BJT）的模型参数](../images/table-03-03a.png)

![表 3.3（续）　双极性晶体管（BJT）的模型参数](../images/table-03-03b.png)

晶体管的型号（模型名称）不同，参数值当然也不同。商业版 SPICE 的元件库通常收录许多元件模型；评价版与免费版的模型库往往较少，使用时可能必须自行决定参数值，或以适当方法取得元件模型。

### 3.1.5　借助 SPICE 的模拟种类

SPICE 的基本模拟分析方法有以下三种：

- **DC 分析**：令输入电压（或电流）变化，模拟随之变化的输出电压（或电流），相当于用 X-Y 示波器观测输入—输出特性。
- **AC 分析**：模拟电路的振幅—频率特性和相位—频率特性。
- **暂态分析（Transient Analysis）**：向电路输入正弦波、脉冲波等信号，并像使用示波器一样观测各部分的电压或电流波形。

除此之外，还可执行 FFT 分析、噪声分析、蒙特卡洛（Monte Carlo）分析、温度分析等多种模拟。

#### 网表

简要说明 List 3.1 的内容。第 3～21 行列出各元件的连接节点、元件值和模型名。例如一行晶体管记录依次给出集电极、基极、发射极所连接的节点以及晶体管模型名。

第 6、7、14、16、21 行中的 `OUT` 是图 3.1 节点 8 的别名（Alias）。为输入端、输出端和电源端适当设置别名，可提高网表的可读性。GND 的节点编号固定为 0；例如负载电阻一行表示把 \\(R_L=1\ \mathrm{k\Omega}\\) 连接于 OUT（节点 8）与 GND 之间。

第 23～26 行指定二极管和双极结晶体管（BJT）的模型。一般写法为：

```text
.MODEL <模型名> <元件类型> (<参数名>=<值> ...)
```

其中元件类型如表 3.4 所列。

![表 3.4（上）　元件类型一览](../images/table-03-04a.png)

<!-- 来源：PDF 第 71 页；原书第 57 页 -->

![表 3.4（续）　元件类型一览](../images/table-03-04b.png)

例如：

```text
.MODEL D1S1588 D (IS=4.4E-14 RS=3.8)
```

表示：

- `D1S1588` 是 1S1588 的自制模型名；
- `D` 表示二极管模型；
- \\(I_S=4.4\times10^{-14}\ \mathrm{A}\\) 是饱和电流；
- \\(R_S=3.8\ \Omega\\) 是寄生串联电阻。

这个模型等效于理想二极管串联寄生电阻 \\(R_S\\)，如图 3.4 所示。

![图 3.4　理想二极管与计入寄生串联电阻后的电流—电压特性](../images/fig-03-04.png)

二极管还有许多其他模型参数。这里只指定 \\(I_S\\) 与 \\(R_S\\)，其余参数由 SPICE 采用默认值。2SC1815 的自制模型同样只给出七个关键参数，省略的项目采用表 3.3 的默认值。网表末尾的 `.TRAN`、`.AC` 和绘图命令依次指定暂态分析、AC 分析和结果显示；以 `#` 开头的命令供 WinSpice3 使用，在其他 SPICE 中可作为注释忽略。
