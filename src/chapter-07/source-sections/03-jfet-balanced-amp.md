### 7.3.2　基于 Difet Process 的 OPA627/637

此运算放大器就是 TI 公司采用介质分离 Process Difet 的 JFET 输入运算放大器。Difet 成本虽比 BiFET 高，但能够减小栅极漏电流和栅极输入电容。

OPA627 与 OPA637 虽然电路构成相同，但只有隐藏的相位补偿电容不同。OPA627 以整体反馈稳定工作，OPA637 则在噪声增益在 5 倍以上时稳定工作。

现将 OPA627 的简略等效电路表示于图 7.19。\\(Q_3\\)、\\(Q_4\\) 与 \\(Q_5\\)、\\(Q_6\\) 是电流镜像。在此电路上（\\(Q_3\\) 与 \\(Q_5\\) 的发射极面积比）与（\\(Q_4\\) 与 \\(Q_6\\) 的发射极面积比）要是均为 \\(n\\) 时，则下式就成立。

\\[ I_{C3} + I_{C4} = \left(\frac{n}{n+1}\right)I_1 = \text{一定} \tag{7.24} \\]

![图 7.19 OPA627/637 的简略等效电路](../images/fig-07-19.png)

也就是说 \\(Q_5\\)、\\(Q_6\\) 是被 \\(J_1\\)、\\(J_2\\) 所驱动的基极接地差动放大电路。

另外，\\(J_1\\)、\\(J_2\\) 属漏极（Drain）接地。初级的跨导 \\(g_m\\) 可用下式表达。

\\[ g_m = \frac{n}{n+1}\left\lbrace\frac{1}{\frac{1}{g_{m1}} + \frac{1}{g_{m2}} + R_1 + R_2 + \frac{4V_T}{I_1}}\right\rbrace \tag{7.25} \\]

其中，\\(g_{m1}\\) 为 \\(J_1\\) 的跨导（S）；\\(g_{m2}\\) 为 \\(J_2\\) 的跨导（S）；\\(V_T\\) 为热电压（=25.85 mV）（当 300 K 时）；\\(I_1\\) 为定电流源 \\(I_1\\) 的电流值（A）。

\\(Q_7\\) 与 \\(Q_8\\) 是用于 Boot strape \\(J_1\\)、\\(J_2\\) 的漏极保持 \\(V_{DS}\\) 为一定值，抵消栅极、漏极间电容 \\(C_{GD}\\) 对 \\(V_{DS}\\) 的依赖性。

\\(Q_3\\) 与 \\(Q_4\\) 是用于限制输出短路时的输出电流，输出电流要是是在 ±45 mA 以内时，实质上为非导通。

OPA627 的初级有许多噪声源，但输入换算噪声电压为 5.6 \\(nV/\\sqrt{\\mathrm{Hz}}\\)（当 1 kHz 时）微小时，表示 \\(J_1\\) 与 \\(J_2\\) 的 \\(g_m\\) 值非常大。

### 7.3.3　显示高速性的重要参数——上升时间

作为评价高速性的参数（Parameter），与转换速率（Slew rate）同等重要的还有被称为上升时间参数。上升（Settling）时间，是指阶跃响应（step response）对常态振幅输入指定误差为止的时间（参照图 7.20），通常误差都指定为 to 0.1% 或 to 0.01%。

![图 7.20 上升时间的定义](../images/fig-07-20.png)

一般情况下，高速宽频带型运算放大器虽然上升时间短，但相位容限少，相位随着频率一起做复杂变化的 Feed Forward 补偿运算放大器，由于响应的过冲（Overshoot），以致上升时间有增长的倾向。

AD845 与 OPA627 的上升时间反映出真实的相位特性，而呈现相应转换速率和 GB 积的微小值（参照表 7.5）。

### 7.3.4　OPA627 在宽频带平衡放大器方面的应用

图 7.21 是驱动 Seelas Logic 公司 A-D Converter CS5396 的平衡放大器（差动输入/差动输出放大器）的例子 <sup>[26]</sup>。此 CS5396，是最大取样频率 = 96 kHz/24 bit，分辨能动态范围 120 dB 的超高性能的 ΔΣ 型 A-D Converter <sup>[27][28]</sup>，欲充分（100%）发挥其实力，驱动放大器需满足以下条件：

- THD < 0.0001%（20 Hz—20 kHz）；
- 总输出噪声电压 < 2 μV\\(_{RMS}\\)（20 Hz—20 kHz）；
- 最大输入电压 = 13 V\\(_{RMS}\\)/最大输出电压 = ±2 V；
- 可在 100 Ω 负载供给 ±20 mA 的电流。

![图 7.21 用于驱动 A-D 变换器 CS5396 的平衡放大器（单频道）](../images/fig-07-21.png)

为了满足（清除：clear）这些条件，在图 7.21 的放大器中，每个通道（channel）就要放出 3 个 OPA627。此放大器以差动输入为原则，但因馈加有强力的同相负反馈（后述），所以单端（Single ended）接输入（图 7.22）也毫无问题。

### 7.3.5　什么是平衡放大器上的共模抑制比

差动输入−差动输出放大器＝平衡放大器，如此定义增益。

> ▶ 差模增益 \\(A_{VD}\\)
>
> 如图 7.23（a）所示，当输入端子 1 供加以 \\((+V_{ID}/2)\\)，输入端子供加以 \\((-V_{ID}/2)\\) 时，出现于输出端子的电压 \\(V_{O1}\\) 与 \\(V_{O2}\\)，可如下定义：
>
> \\[ A_{VD} = \frac{V_{O1} - V_{O2}}{V_{ID}} \tag{7.26} \\]
>
> ▶ 共模增益 \\(A_{VC}\\)
>
> 如图 7.23（b）所示，供加连结两输入端子的共有输入电压 \\(V_{IC}\\) 时，出现于输出端子的电压 \\(V_{O1}\\)、\\(V_{O2}\\) 做如下定义：
>
> \\[ A_{VC} = \frac{(V_{O1} + V_{O2})/2}{V_{IC}} \tag{7.27} \\]
>
> \\(V_{IC}\\) 即 \\([(V_{IN1} + V_{IN2})/2]\\) 叫同相输入电压，\\([(V_{O1} + V_{O2})/2]\\) 则叫同相输出电压。

![图 7.23 平衡放大器的差模增益与共模增益](../images/fig-07-23.png)

> ▶ 运算放大器的差模增益与共模增益
>
> 请看图 7.24。通常的运算放大器均为单端输出，所以差模增益与共模增益可分别如下定义：
>
> \\[ \text{差模增益 } A_{VD} = \frac{V_{OUT}}{V_{ID}} \tag{7.28} \\]
>
> \\[ \text{共模增益 } A_{VC} = \frac{V_{OUT}}{V_{IC}} \tag{7.29} \\]
>
> 差模增益 \\(A_{VD}\\) 与共模增益 \\(A_{VC}\\) 之比叫做共模抑制比 CMRR（Common Mode Rejection Ratio），通常用 dB 表示。
>
> \\[ \mathrm{CMRR} = 20\lg(A_{VD}/A_{VC})(\mathrm{dB}) \tag{7.30} \\]

![图 7.24 运算放大器的差模增益与共模增益](../images/fig-07-24.png)

### 7.3.6　改善 CMRR 的同相负反馈技术

不改变差模增益而降低共模增益的负反馈，即改善 CMRR 的负反馈称为"同相负反馈"。图 7.21 的 \\(C_5\\) 就是同相负反馈的相位补偿电容。

同相负反馈的稳定性，可用相对于同相信号的环路增益（Loop Gain）的相位容限加以判断。想要计算同相负反馈的环路增益，应把图 7.21 的输入端子 IN+ 与 IN− 分别接地，而且将两输出端子（OUT+ 与 OUT−）加以短路，于是从电路的对称性便推导出图 7.25 的等效电路。

![图 7.25 用来计算同相负反馈的环路增益而设的等效增益](../images/fig-07-25.png)

环路增益 \\(G_L(j\omega)\\) 近似上为：

\\[ G_L(j\omega) = \frac{1}{2}\left(\frac{R_5}{R_6 // R_7}\right)\left(\frac{1}{1 + j\omega R_5 C_5}\right)G_1(j\omega) \tag{7.31} \\]

（\\(G_1(j\omega)\\)：\\(U_1\\) 的总反馈时闭环增益）

同相负反馈的环路增益为 1 倍的频率，即增益交点频率 \\(f_C\\) 近似上可为：

\\[ f_C = \frac{1}{2\pi R_5 C_5} \tag{7.32} \\]

倘若时常数 \\(R_5 C_5\\) 设定得使 \\(f_C\\) 远低于 \\(U_1\\)（OPA627）的单位增益（Unity Gain）频率（=16 MHz）时，便可获得足够的相位容限。

图 7.21 的放大器的 CMRR，当 \\(R_1 = R_2 = R_7 = R_4\\) 且 \\(R_5 = R_7\\) 又 \\(R_8 = R_{10}\\) 成立时，在中频带频率，

\\[ \mathrm{CMRR} = 20\lg\left[\left(1 + \frac{R_5}{R_6}\right)\left(\frac{R_9}{2R_8 + R_9}\right)\right](\mathrm{dB}) \tag{7.33} \\]

此式子，暗示增加 \\(R_5\\) 的值时，CMRR 就增加。原电路的 \\(R_5\\) 为 1 MΩ，但若省去 \\(R_5\\)（也就是取 \\(R_5 = \infty\\)），则 CMRR 就更加改善。再者，纵然省去 \\(R_5\\)，但动作点和差模增益并不改变。
