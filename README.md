# op-amp-internals-and-discrete-design

## 原书与作者

本项目整理的中文版本源自日本电子技术专业出版社 [CQ 出版](https://shop.cqpub.co.jp/hanbai/books/52/52311.html)发行的黑田彻（黒田 徹，日文读音：くろだ とおる）著作《解析 OPアンプ&トランジスタ活用》。CQ 出版将其列入“电子实务系列”。[国会图书馆书目](https://ndlsearch.ndl.go.jp/books/R100000002-I000003673859)和 CQ 提供的[原书资料 PDF](https://www.cqpub.co.jp/hanbai/books/I/I000028/I000028.pdf)均将 2002 年 9 月 15 日记为该书的初版发行日；PDF 另记载 2005 年 2 月 1 日第 2 版。CQ 现售页面所称“复刻版／按需版”是后来的再版产品，现有可靠书目中尚未发现早于 2002 年的同名原版。书中从市售运算放大器 IC 的内部电路入手，分析增益、精度、噪声与带宽，并进一步讨论分立晶体管运算放大器的设计。

CQ 出版提供的 [原书资料 PDF](https://www.cqpub.co.jp/hanbai/books/I/I000028/I000028.pdf)记载：黑田彻 1945 年生于日本兵库县，1970 年毕业于神户大学经济学部，1971 年进入日本电音株式会社技术部，翌年离职；资料发布时任“黒田電子技術研究所”所长。该资料还列出他的其他著作，包括 CQ 出版的《はじめてのトランジスタ回路設計》，以及ラジオ技術社出版的《基礎トランジスタ・アンプ設計法》和《最新トランジスタ・アンプ設計法》。

互联网上还有一个题为 [“Kuroda TL071 60W FET Amp (1982)”](https://www.diyaudio.com/community/threads/kuroda-tl071-60w-fet-amp-1982.164476/) 的 diyAudio 讨论帖。该帖发表于 2010 年，并链接到[原始日文页面](http://home.b04.itscom.net/helium/audio/poweramp/index.html)；它不是电路的原始来源。原始页面所列出处为：黑田彻，《制造 FET 60W 立体声功率放大器》，《无线电技术》，1982 年 9 月，无线电技术社。

以上就是黑田先生在互联网上能找到的所有资料了。目前除这些出版物中的作者简介外，本项目尚未找到能够独立核验该研究所沿革或现状的公开网页；网络上名称含“黑田”或“Kuroda”的其他电子实验室、研究所和公司，也不应在缺乏证据时视为同一机构或与作者有关。

## 为什么制作这个项目

首先，这是一本罕见而实用的模拟电路著作，深入分析 AD797、NE5532、OPA627 等经典型号的内部结构与工作原理，并提出了自己的分立运放架构和独特的Cob失真抵消电路。这些器件至今仍常见于 Hi-Fi 音频电路，因此书中的分析对于理解和设计高品质模拟音频设备仍有很高的参考价值。

我所使用的原始纸书是中文译本，后来得到的电子版本则以扫描图像为主：很难全文检索、引用，也不便由 AI Agent 准确处理。为此，我把它重制为结构化的 Markdown 文本，作为自己的长期参考资料，也分享给所有对模拟电子技术感兴趣的读者。我已经在自己的 AI 辅助工作中使用这些经过转换和校对的内容，帮助 AI 更准确地检索、理解和引用书中的知识；如果这份电子版也能为中文 AI 工具及其使用者提供可靠、易于处理的模拟电子技术资料，我会非常高兴。目前本项目仅有中文版本。

在整理过程中，我逐字复核正文、公式与元件参数，并对中文纸书中能够确认的明显错漏以及 OCR 引入的错误作了修正，同时尽量保留原书的技术含义、章节结构、图号与公式编号。黑田先生生于 1945 年；如果仍然健在，他在 2026 年应该已经80岁了。我相信，他会欣慰地看到自己的工作在 AI 时代以一种更容易检索、学习和延续的形式保存下来。

具体重制工作包括：

- 正文转录为 UTF-8 Markdown；
- 公式转换为 LaTeX，并保留原公式编号；
- 电路图、曲线图和照片保留为原扫描裁图；
- 保留章节号、图号、元件标号以及原书页码追踪信息；
- 每章完成中文核对后，才考虑制作英文译本。

本仓库当前不是英文翻译项目，也不以未经校验的整书 OCR 输出作为最终内容。

## 阅读与构建

安装 [mdBook](https://rust-lang.github.io/mdBook/guide/installation.html) 后，在仓库根目录运行：

```powershell
mdbook build
```

生成的网站位于 `book/`。本地预览：

```powershell
mdbook serve --open
```

推送到 `main` 分支后，GitHub Actions 会自动构建并发布 GitHub Pages。

## 内容与工具

- `src/SUMMARY.md`：mdBook 目录，包含第 1～8 章及附录 A、B、C
- `src/introduction.md`：项目说明、原书与作者资料、转录约定和项目动机
- `src/transcription-style.md`：编辑、排版、数学格式、代码和校对规范
- `src/verification.md`：全书验证总览、校对状态、构建检查和已知问题
- `src/chapter-01/` ～ `src/chapter-08/`：各章合并稿、分节源文件、扫描裁图和章节验证记录
- `src/chapter-03/appendix-a.md`、`appendix-b.md`：第 3 章附录 A、B
- `src/chapter-04/appendix-c.md`：第 4 章附录 C，以及对应的扫描图和代码整理
- `tools/build_chapter*.ps1`：早期章节合并稿和裁图的重建脚本
- `tools/crop_chapter*_*.py`、`tools/crop_appendix_ab_assets.py`：各章和附录图像裁切脚本
- `tools/contact_sheet.py`、`tools/figure_blocks.py`、`tools/figure_labels.py`：图像接触表、图块识别和图注辅助工具
- `tools/rebuild_images.py`、`tools/resnap_crops.py`、`tools/warm_label_cache.py`：批量重建、重新裁切和图注缓存工具
- `tools/ocr_scanned_chinese.ps1`：Windows 简体中文 OCR 初稿工具

## 工作原则

1. 中文版的准确性优先于处理速度。
2. OCR 只用于生成初稿，正文、公式和图号需要对照扫描页复核。
3. 不自动重绘原电路图，避免在重绘过程中引入连接或数值错误。
4. 中文章节没有完成核对前，不开始对应的英文翻译。
5. 分节源文件和合并后的章节文件同时保留，以便修订和发布。
